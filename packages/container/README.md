# @fougere/container
> L'interface du conteneur DI
L'interface seule, sans implémentation et sans dépendance — de quoi écrire du code
qui résout ses dépendances sans épouser un conteneur particulier.

## Installation
```bash
pnpm add @fougere/container
```

---

Fait partie de [Fougere](https://github.com/chok/fougere) — un schéma unique,
un gradient du monolithe au distribué, le même code utilisateur.
Documentation de référence : le site (`site/content`, fr/en).
