# @fougere/runtime
> Le boot conventionnel
`bootAppFromConfig()` et `resolveStorage()` — **l'unique** endroit qui nomme un paquet
de stockage. Changer de moteur est un changement ici, et nulle part ailleurs.

## Installation
```bash
pnpm add @fougere/runtime
```
