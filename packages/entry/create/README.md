# create-fougere

> Scaffold a Fougere workspace

```bash
npm create fougere shop --frond blog --app nuxt
```

`pnpm create`, `bun create` and `yarn create` work the same: the project is written for the
package manager that ran the command — its scripts, its workspace file, its build permissions.

Everything after the name is read by `fougere new`, so every flag it declares
works here: `--frond`, `--app`, `--bare`, `--force`. With no flags and
a terminal, it asks.

**[Documentation →](https://fougere.dev/)**
