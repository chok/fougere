---
title: "Finish a fact"
description: "Transform a fact before any subscriber reads it."
kind: "task"
uses: ["fact"]
forms: ["Pipe<T>", "pipes:"]
---

An operation that takes `Pipe<T>` answers the fact every subscriber then reads. It is for what
must be TRANSFORMED — a hash `pick` cannot produce, a lookup needing a dependency the announcer
should not hold — never for dropping a field: a fact is already a projection, so what should not
travel is simply not declared.

```ts
// fronds/privacy/handlers/HashHandler.ts
async set(fact: Pipe<PostPublished>): Promise<PostPublished> {
  return { ...fact, author: this.salt.hash(fact.author) };
}
```

Several links run in the order the fact's OWNER declares, each reading what the previous one
answered:

```ts
// fronds/blog/frond.config.ts — blog owns `postPublished`
export default { pipes: { postPublished: ['TenantHandler', 'HashHandler'] } };
```

Two links with no order refuse the boot, naming both; a link the order does not list refuses
too, and so does a frond ordering a fact it does not own. A link that answers nothing is
refused. A link is a hard dependency where a subscriber is not: a subscriber that throws is
logged and the announcement goes on, a link that throws stops it. And since a link is called,
it has an address — local, or named in `fronds:` — and never sits behind a carrier.

See [pipe-split](https://github.com/chok/fougere/tree/main/demos/pipe-split).
