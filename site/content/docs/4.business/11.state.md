# Caller state

A source keeps rows; some things belong to the caller instead — a cart before sign-in, a chosen
locale. An op asks for `State` and reads or writes it by name:

```ts
import type { State } from '@fougere/core';

export default class CartHandler {
  async open(state: State) {
    state.set('cart', 'c42');

    return { opened: true };
  }

  async current(state: State) {
    return { cart: state.get<string>('cart') ?? null };
  }
}
```

The op names no cookie and no header. How each name is kept is the operator's, in
`fougere.config.ts`, and a package brings the way to keep it:

```ts
import '@fougere/state-cookie';

export default defineFougere({
  state: { cart: { cookie: { maxAge: 604800 } } },
});
```

A cookie is `HttpOnly`, `SameSite=Lax` and `Path=/` unless the entry says otherwise
(`sameSite: 'none'` adds `Secure`). `state.forget('cart')` removes it.

## What travels, and what is written

- **Signed, not encrypted.** The value leaves with a signature made with `FOUGERE_STATE_KEY`. The
  caller can read it and cannot change it: a changed value reads as absent. What must stay hidden
  is kept as a reference, the row it names kept in a source.
- **Written only on an answer.** What the calls of a request wrote leaves with the answer; a
  refused request keeps nothing.
- **One request, every call.** A GraphQL document making three calls writes once, with the answer.
- **Every HTTP door carries it** — REST, GraphQL, and the envelope a page calls. A call one process
  makes to another carries no caller state: it has no caller.

## What is refused

- `state.set` on a name `state:` does not declare, or one the door cannot carry, naming what the
  door keeps.
- `state.set` outside a request at a door — a call made in process, or a runtime with no async
  context. On a Worker, `nodejs_compat` is that context; `fougere check` names a
  `wrangler` config declaring `state:` without it (`state-without-async-context`).
- With no `FOUGERE_STATE_KEY`, the boot warns: the key dies with the process, so a restart or a
  second replica reads every value as absent.
