# Demos

Every page of this documentation shows fragments. These are the projects those fragments
are cut from: complete, running, and read straight out of the repository rather than
copied into a page.

Pick one, open any file, and run the ones that do not need a native binary.

::demo-list
::

Each demo also runs locally, which is the only way to see the ones that hold a database:

```bash
git clone https://github.com/chok/fougere.git
cd fougere && pnpm install && pnpm run build
pnpm -C demos/nuxt-blog dev
```
