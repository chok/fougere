A frond never imports another frond's files. It asks for the other frond's handler by type — `Facade<ProductHandler>` — and calls its methods. Whether that frond runs in this process or in another one is said by the config, never by this line.

A frond is a directory under `fronds/`. It holds its own entities, handlers, services and
repositories:

```
fronds/
  catalog/     Product, ProductHandler
  pricing/     PriceHandler
  cart/        CartHandler
```

A frond does not import another's files. It asks for another frond's facade, by type:

```ts
// fronds/pricing/handlers/PriceHandler.ts
import type { Facade } from '@fougere/core';
import type ProductHandler from '@fronds/catalog/handlers/ProductHandler.js';

export default class PriceHandler {
  constructor(private catalog: Facade<ProductHandler>) {}

  async getTotal(): Promise<number> {
    const products = await this.catalog.list();

    return products.items.reduce((sum, product) => sum + product.cents, 0);
  }
}
```

```ts
// fronds/cart/handlers/CartHandler.ts
import type { Facade } from '@fougere/core';
import type PriceHandler from '@fronds/pricing/handlers/PriceHandler.js';

export default class CartHandler {
  constructor(private pricing: Facade<PriceHandler>) {}

  async getSummary(): Promise<{ cents: number }> {
    return { cents: await this.pricing.getTotal() };
  }
}
```

`fougere graph` prints the three fronds and which one calls which.

## Reaching another Frond

A Frond does not import another's files: it goes through its facade. `Facade<T>` is the
framework's second port, resolved by type like a repository (`Repository<Post>`):

```ts
import type { Facade } from '@fougere/core';
import type ArticleHandler from '@fronds/stock/handlers/ArticleHandler.js';

export default class CommandeHandler {
  constructor(private articleFacade: Facade<ArticleHandler>) {}

  /** Can this order be served from the shelf? */
  async servable(sku: string): Promise<boolean> {
    const onHand = await this.articleFacade.onHand(sku);
    return onHand > 0;
  }
}
```

Three things to see:

- **It takes what the handler takes.** `onHand(sku)` on the facade is `onHand(sku)` on the
  handler, checked by TypeScript, and it always answers a promise: the call may cross a
  network.
- **`keyof T` is exactly the right set.** The scan skips `private` and `protected`, so a
  handler's public methods *are* its operations — and `keyof` excludes the rest for the
  same reason.
- **The signature says nothing about where the other Frond runs.** The same type resolves
  the local façade or a remote stand-in. Declaring `stock` in `fronds:` does not change this line.

Asking for the handler itself — `constructor(private articles: ArticleHandler)` — is refused at boot
from another Frond, naming the facade: the bare class would skip validation, middlewares and
placement, and break the day `stock` moved. Inside its own Frond, a class asking for `ArticleHandler`
is handed the instance its facade calls.

You pass **everything**, the user included. A collector reads a request, and code holds
none: it already has the user, so it hands it over like any other argument. If the called
operation takes `user?: User`, write `this.articleFacade.reserve(sku, user)`; leave it out
and the operation receives no user. For the same reason a presenter adds nothing to what a
facade answers: you get the rows the handler returned. Collectors and presenters belong to
the doors — REST, GraphQL, the page — which receive a request from outside.

### Announcing a fact

A call names one recipient; an emission names a **subject**. `Emit<T>` is a constructor
dependency like any other, and accepting a `Fact<T>` IS the subscription — no topic, no
register call.

See [Facts](/docs/concepts/fact) — the resolver, what crosses a process, and what to do
when a fact's shape moves.

### Writing several entities as one

`Storage<T>`'s unit is one statement. When two writes must both land or neither,
`Together<[Account, Ledger]>` is the fourth port, read like the other three — its unit is a
block:

```ts
constructor(private together: Together<[Account, Ledger]>) {}

await this.together.run(async ([accounts, ledger]) => { … });
```

See [Writes that stand or fall as one](/docs/data/together) — the two realizations, and
which one you get.
