title: "A frond in another language"
description: "A Rust or Python process answering the same calls."
kind: "extending"
---

None of this assumes TypeScript. A frond written in another language joins the topology if
it honours three things:

1. **the wire** — `POST /_fougere/call`, JSON-RPC 2.0, `method = "address.op"`;
   see [The gradient](/docs/concepts/configuration).
2. **the card** — `rpc.discover` returns the envelope above, `x-fougere-version: 1`.
3. **the error vocabulary** — a whole `FougereError` in `error.data`, its `code` a
   [semantic code](/docs/concepts/handler); the `-32000` integer stays the JSON-RPC spec's.

The consumer then rebuilds the schema and validates data locally with the same rules.

`demos/rust-frond/` is one, in Rust — one entity, three operations, no `entity({...})`
class anywhere.
