---
title: "Teach a word"
description: "A string format, a generator or a verb every entity can name."
kind: "extending"
---

`vocabulary/` holds the words a Frond adds to the declaration — a generator, a format, a
verb. A file there exports each as a term, and the process lists them beside its fronds: a
registry answers every entity, whichever Frond the file sits in. An entity still names the
word, and the boot refuses a name nothing answers.

```ts
// fronds/blog/vocabulary/ulid.ts
import { Generators } from '@fougere/schema';

export const ulid = Generators.term('ulid', () => …);

// fronds.ts — written by the scan, or by hand
export const vocabulary = [ulid];

// fronds/blog/entities/Post.ts
id: primary({ generate: 'ulid' }),
```
