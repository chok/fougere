# Choose how it runs

The code of the shop names no process, no provider, no database and no protocol. Those
choices live in one file at the root of the project, `fougere.config.ts`, and none of them
changes a line under `fronds/`.

```ts
// fougere.config.ts
import { defineFougere } from '@fougere/core';

export default defineFougere({
  fronds: { catalog: 'http://127.0.0.1:4620' },
  ports: { Payment: 'StripePayment' },
  db: { path: '.data/shop.db' },
  adapters: { rest: true },
});
```

Each section below is one of these keys. Leave a key out and you get the default: every
frond in the app's process, the only implementation of each port, rows kept in memory (a
warning says so), and no REST or GraphQL.

## Where each frond runs

`fronds:` gives a frond an address. Start the catalog alone:

```bash
fougere serve catalog --port 4620
```

and name that address:

```ts
fronds: { catalog: 'http://127.0.0.1:4620' },
```

`PriceHandler` keeps calling `this.catalog.list()`; the call now crosses the network.
Remove the line and the catalog runs in the app's process again.

## What answers a port

When two classes extend `Payment`, the app stops at boot until `ports:` says which one
answers:

```ts
ports: { Payment: process.env.NODE_ENV === 'production' ? 'StripePayment' : 'FakePayment' },
```

The same key stacks classes in front of it, from the outside in. `RetryingPayment` extends
`Payment` and asks for one, so it wraps whatever comes after it in the list:

```ts
ports: { Payment: ['RetryingPayment', 'StripePayment'] },
```

`CheckoutHandler` still asks for `Payment`, and never learns which one it got.

→ [Ports](/docs/business/ports)

## Where rows live

`db:` is the database every entity lands in by default. `sources:` moves some entities
elsewhere: another database, a directory of JSON files, or memory.

```ts
db: { path: '.data/shop.db' },
sources: {
  archive: { source: 'file', path: './archive', entities: ['Order'] },
},
```

`Order` is now read and written as files under `archive/`; every other entity stays in
`db`. The repository a handler asks for is the same either way.

→ [Sources](/docs/infra/sources)

## What the app serves

`adapters:` says which APIs the app answers on, beside the calls its own pages make. The
operations are served on each one:

```ts
adapters: { rest: true, graphql: true },
```
