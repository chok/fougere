# Vues

Une vue est une classe de schéma dérivée. Elle se déclare **depuis** l'entité, jamais à
rebours de ce qu'une requête a sélectionné :

```ts
/** Ce qu'un auteur peut écrire. */
export class PostDraft extends Post.pick('slug', 'title', 'summary', 'body') {}

/** Ce que l'index public montre — pas de body. */
export class PostCard extends Post.pick('id', 'slug', 'title', 'summary', 'publishedAt') {}

/** L'entrée d'une opération de lecture custom. */
export class BySlugInput extends Post.pick('slug') {}
```

Une vue est une classe de schéma complète : elle a `getFields()`, `validate()`, et
s'utilise comme type TypeScript. Les vues se chaînent : `Post.pick(…).partial()`.

## Les quatre dérivations

| Dérivation | Produit |
|---|---|
| `Post.pick('a', 'b')` | ces champs seulement |
| `Post.omit('a')` | tous les champs sauf ceux-là |
| `Post.partial()` | chaque champ optionnel — **valide en patch** : un champ absent signifie « intouché », jamais « forgé » |
| `Post.extend({ extra: text() })` | l'entité plus des champs — c'est ainsi que `User` étend `AuthUser` |

Le mode de la vue voyage avec elle : une vue `partial()` utilisée comme entrée d'opération
valide automatiquement en mode patch.

## Où les vues se branchent

- **Entrées de handler** — déclarez la vue comme type du paramètre ; la façade valide le
  body du fil contre elle avant votre code ([Handlers](/fr/docs/business/handlers)).
- **Sorties de handler** — `Crud(Post, PostPublic)` restreint chaque lecture aux champs de la vue.
- **Formulaires** — `useFormFor(PostDraft)` dérive ses champs de la vue ([Formulaires](/fr/docs/client/forms)).

## Les projections io

L'axe boundary dérive deux ensembles de champs que toutes les surfaces utilisent :

```ts
inputFields(Post.getFields())    // les champs qu'un client peut ÉCRIRE — readOnly exclus
outputFields(Post.getFields())   // les champs qu'un client peut LIRE  — writeOnly exclus
```

C'est pourquoi un formulaire bâti sur `Post` ne montre jamais d'inputs `status` ou
`publishedAt`, sans aucune configuration par formulaire — la projection est l'énoncé unique.
