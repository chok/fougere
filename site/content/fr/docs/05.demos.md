# Démos

Chaque page de cette documentation montre des fragments. Voici les projets dont ces
fragments sont tirés : complets, qui tournent, et lus directement dans le dépôt plutôt que
recopiés dans une page.

Choisissez-en une, ouvrez n'importe quel fichier, et lancez celles qui ne demandent pas de
binaire natif.

::demo-list
::

Chaque démo tourne aussi en local, seule façon de voir celles qui tiennent une base de
données :

```bash
git clone https://github.com/chok/fougere.git
cd fougere && pnpm install && pnpm run build
pnpm -C demos/nuxt-blog dev
```
