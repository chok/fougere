# Stocker vos données

La boutique du [premier guide](/fr/docs/guides/business-logic) renvoie un total écrit dans
le code. Ce guide stocke de vrais produits : une entité, un repository, et un formulaire
pour en ajouter.

## Entités

Une entité est une classe dans `entities/` qui décrit un type de données :

```ts
// fronds/shop/entities/Product.ts
import { entity, primary, text, number } from '@fougere/schema';

export default class Product extends entity({
  id: primary(),
  title: text({ min: 1, max: 200 }),
  cents: number({ min: 0 }),
}) {}
```

À partir de cette classe, Fougere construit la table `products`, la validation de chaque
entrée, et les champs d'un formulaire.

`Crud(Product)` donne à un handler les cinq opérations habituelles — `list`, `get`,
`create`, `update`, `delete` :

```ts
// fronds/shop/handlers/ProductHandler.ts
import { Crud } from '@fougere/core';
import Product from '../entities/Product.js';

export default class ProductHandler extends Crud(Product) {}
```

## Migrations

La table n'existe pas encore, et l'app ne la crée pas pour vous : elle refuse de démarrer, et
dit ce qui manque.

```
Fougere boot refused: the database is behind the entities (1):
  products — no table
  Read the plan: fougere migrate — then write it: fougere migrate --apply
```

`pnpm migrate` — `fougere migrate --apply` — la crée. Lancez-le chaque fois qu'une entité gagne
un champ ; le démarrage vous le dit.

Un renommage se déclare sur l'entité, et les lignes suivent :

```ts
export default class Product extends entity(
  { id: primary(), name: text(), cents: number({ min: 0 }) },
  { previous: { name: 'title' } },
) {}
```

`fougere migrate` affiche `products: title → name`, et `--apply` renomme la colonne.

→ [Comment un schéma bouge](/fr/docs/schema/evolution)

## Repositories

Un repository est l'endroit où les lignes d'une entité sont lues et écrites. Chaque entité
en a déjà un ; écrivez la classe quand une requête mérite un nom :

```ts
// fronds/shop/repositories/ProductRepository.ts
import { Repository } from '@fougere/core';
import Product from '../entities/Product.js';

export default class ProductRepository extends Repository(Product) {
  cheapest(): Promise<Product[]> {
    return this.list({ orderBy: 'cents', limit: 5 });
  }
}
```

Un repository est un service, comme `Payment` : un handler le demande par son type.

```ts
// fronds/shop/handlers/CartHandler.ts
import ProductRepository from '../repositories/ProductRepository.js';

export default class CartHandler {
  constructor(private products: ProductRepository) {}

  async getTotal(): Promise<number> {
    const products = await this.products.list();

    return products.reduce((sum, product) => sum + product.cents, 0);
  }
}
```

## Formulaires

`useFormFor` construit l'état d'un formulaire à partir de l'entité. Il vérifie dans le
navigateur ce que le serveur vérifie : un titre vide ou un prix négatif est refusé avant
tout envoi.

```vue
<script setup lang="ts">
import Product from '@fronds/shop/entities/Product.js';

const { values, errors, submit, loading } = useFormFor(Product);
</script>

<template>
  <form @submit.prevent="submit">
    <input v-model="values.title" />
    <p v-if="errors.title">{{ errors.title }}</p>
    <input v-model.number="values.cents" type="number" />
    <p v-if="errors.cents">{{ errors.cents }}</p>
    <button :disabled="loading">Ajouter</button>
  </form>
</template>
```

`submit` appelle `create`. Une fois la création réussie, chaque page qui liste des produits
se met à jour d'elle-même.
