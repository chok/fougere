# Organiser votre topologie

Jusqu'ici, la boutique est une seule Frond. Ce guide la découpe en trois — le catalogue,
les prix, le panier —, les fait s'appeler entre elles, puis fait tourner le catalogue dans
son propre process sans toucher à leur code.

## Fronds

Une Frond est un dossier sous `fronds/`. Elle contient ses propres entités, handlers,
services et repositories :

```
fronds/
  catalog/     Product, ProductHandler
  pricing/     PriceHandler
  cart/        CartHandler
```

Une Frond n'importe pas les fichiers d'une autre. Elle demande la façade de l'autre Frond,
par son type :

```ts
// fronds/pricing/handlers/PriceHandler.ts
import type { Facade } from '@fougere/core';
import type ProductHandler from '@fronds/catalog/handlers/ProductHandler.js';

export default class PriceHandler {
  constructor(private catalog: Facade<ProductHandler>) {}

  async getTotal(): Promise<number> {
    const products = await this.catalog.list();

    return products.items.reduce((sum, product) => sum + product.cents, 0);
  }
}
```

```ts
// fronds/cart/handlers/CartHandler.ts
import type { Facade } from '@fougere/core';
import type PriceHandler from '@fronds/pricing/handlers/PriceHandler.js';

export default class CartHandler {
  constructor(private pricing: Facade<PriceHandler>) {}

  async getSummary(): Promise<{ cents: number }> {
    return { cents: await this.pricing.getTotal() };
  }
}
```

`fougere graph` affiche les trois Fronds et laquelle appelle laquelle.

## Déplacer une Frond

Pour faire tourner le catalogue dans son propre process, lancez-le seul :

```bash
fougere serve catalog --port 4620
```

puis donnez-lui cette adresse dans `fougere.config.ts` :

```ts
export default defineFougere({
  fronds: { catalog: 'http://127.0.0.1:4620' },
});
```

`PriceHandler` continue d'appeler `this.catalog.list()` de la même façon ; l'appel passe
maintenant par le réseau. Retirez la ligne, et le catalogue tourne de nouveau dans le
process de l'app.
